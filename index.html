KeepNote

2026

A native macOS app that keeps Markdown notes tucked along the screen edge, ready to open without interrupting your work. Built with Swift, AppKit and SwiftUI, with SQLite persistence and versioned migrations. Note bodies are encrypted in the local database with AES-GCM and a Keychain-held key. Implemented folder-based sync with conflict preservation, automated logic and integration tests, and DMG release packaging.

App nativo para macOS que mantém notas em Markdown na borda da tela, prontas para abrir sem interromper o trabalho. Desenvolvido em Swift, AppKit e SwiftUI, com persistência em SQLite e migrações versionadas. O corpo das notas é criptografado no banco local com AES-GCM e chave no Keychain. Implementei sincronização por pasta com preservação de conflitos, testes automatizados de lógica e integração e empacotamento de releases em DMG.

A film review analysis platform. Built a modular Python pipeline to collect and sample Letterboxd reviews, enrich them with TMDB data, and classify themes with LLMs. Frequencies are calculated in code and passed to the narrative stage as structured briefings. Evaluated classification against 100 human-labeled reviews, with paired bootstrap comparisons; added caching, batch recovery and a responsive JavaScript interface.

Plataforma de análise de avaliações de filmes. Desenvolvi um pipeline modular em Python para coletar e amostrar avaliações do Letterboxd, enriquecer os dados via TMDB e classificar temas com LLMs. As frequências são calculadas em código e fornecidas à etapa de síntese como briefings estruturados. Avaliei a classificação contra 100 avaliações com rótulos humanos, com comparações por bootstrap pareado; implementei cache, retomada de lotes e uma interface responsiva em JavaScript.

quantlab

2026

A backtesting platform for US stocks, from market data ingestion and validation to portfolio simulation and risk reports. Built a multi-asset engine with long/short positions, trading costs, slippage, margin and liquidation. Mutation tests check that future data cannot change past decisions, while walk-forward evaluation separates strategy selection from assessment. Documented experiments cover 20 assets and roughly 10 years of history.

Plataforma de backtesting para ações americanas, da ingestão e validação de dados à simulação de carteiras e relatórios de risco. Desenvolvi um motor multiativo com posições long/short, custos, slippage, margem e liquidação. Testes de mutação verificam que dados futuros não alteram decisões passadas, e a avaliação walk-forward separa seleção e avaliação de estratégias. Os experimentos documentados abrangem 20 ativos e cerca de 10 anos de histórico.

Implemented Parquet processing, validated and idempotent PostgreSQL loads, versioned migrations and scheduled ETL runs with GitHub Actions. The published dashboard reads static JSON snapshots; an optional Gemini integration generates analyses with structured claim validation and caching.

Protótipo funcional para explorar dados de jogos da NFL, combinando um pipeline ETL em Python, uma API REST em Java/Spring Boot e um dashboard em React/TypeScript. Implementei processamento de Parquet, cargas validadas e idempotentes no PostgreSQL, migrations versionadas e execução agendada do ETL com GitHub Actions. O dashboard publicado consome snapshots JSON estáticos; uma integração opcional com Gemini gera análises com validação estruturada de afirmações e cache.

Toon In

2026

A Chrome new-tab extension that turns an episode catalog into a TV-style schedule. Built a deterministic scheduling engine driven by catalog, seed and clock, with CSV import and validation, local storage and browser API integration. The React/TypeScript interface includes themes and keyboard navigation. Automated tests cover parsing, scheduling and simulated extension events; responsive QA covered four viewport widths, from 320 to 1440 px.

Extensão de nova aba para Chrome que transforma um catálogo de episódios em uma grade de programação de TV. Desenvolvi um motor determinístico baseado em catálogo, semente e relógio, com importação e validação de CSV, armazenamento local e integração com APIs do navegador. A interface em React/TypeScript inclui temas e navegação por teclado. Testes automatizados cobrem parsing, programação e eventos simulados da extensão; a revisão responsiva abrangeu quatro larguras, de 320 a 1440 px.

World Cup 2026 PredictorPreditor Copa do Mundo 2026

2026

A live prediction system built to forecast match outcomes and statistics throughout the 2026 FIFA World Cup, generating predictions before kickoff and automatically evaluating its own performance after each match. Comparing two independent data sources uncovered a real bug in yellow card counts, while probability calibration delivered the project's largest improvement in predictive accuracy — the same calibration approach used in risk and credit-scoring models.

Sistema de previsão ao vivo desenvolvido para acompanhar toda a Copa do Mundo de 2026, gerando previsões antes do início de cada partida e avaliando automaticamente o próprio desempenho após os jogos. Durante o projeto, a comparação entre duas fontes independentes revelou um bug real na contagem de cartões, e a calibração de probabilidades foi a melhoria que mais aumentou a precisão do modelo — a mesma abordagem de calibração usada em modelos de risco e scoring de crédito.
